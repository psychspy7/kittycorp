# LISA website development media

These are real retained LISA development outputs, not generated stock imagery. See ASSET-PROVENANCE.json for original relative paths and SHA256 checksums. The website uses optimized WebP copies; the original images, Blender sources and LISA application remain in their own project.

- room-preview-v1.webp: furnished room and character development preview.
- rig-review-v1.webp: early multi-pose rig review, with approximate character geometry.
- expressions-v1.webp: painted expression reference sheet, not a finished 3D facial animation.

Captions distinguish painted artwork from the skeletal model and identify unfinished likeness, cloth/hair and object contact. Images do not imply every pictured feature is a shipped product. Later versions should use new filenames, because bundled versioned assets use immutable caching. Studio uploads use new UUID filenames automatically.
