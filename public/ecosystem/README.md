SVGL is a third-party vector catalogue with brand-source references; those files are not claimed to be first-party downloads. Original asset colors and geometry are retained. The monochrome presentation and hover treatment are applied through CSS, not changes to the SVG paths.

KITTY CORP uses its existing original `public/brand/monogram-small-v1.webp`. The supplied artwork is raster; it is preserved instead of inventing a vector replacement. All twelve third-party mark files are native SVGs, without scripts or external asset dependencies.

Maintain entries in `lib/technology-ecosystem.ts`. Use a new versioned filename when replacing a mark, and keep its aspect ratio and source record accurate. Both marquee copies must use the same ordered entries for the seamless loop. Animation controls are shared through `LogoMotionProvider`; reduced motion shows a static footer grid.
